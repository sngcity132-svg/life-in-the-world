# LIFE IN THE WORLD — Version 2.0 : mobilité urbaine

## Changement intégré
- Ajout d'un deuxième car rapide dans la circulation dynamique.
- Ajout d'un taxi jaune supplémentaire.
- Ajout de deux voitures particulières aux couleurs distinctes.
- Les véhicules réutilisent le moteur de circulation, les routes et les interactions déjà présents : ils circulent sur leurs itinéraires et peuvent être approchés/interceptés comme les autres véhicules.

## Limites connues
- Cette version enrichit la circulation dans la carte actuelle de Dakar ; elle n'ajoute pas encore de carte jouable de Kaolack, Thiès, Touba ou d'une ville étrangère.
- Les véhicules ne simulent pas encore les arrêts voyageurs, les horaires de transport, les feux tricolores ou les embouteillages avancés.
- Compilation Next.js et tests sur appareil Android non effectués dans cet environnement.
